# 文档站重构记录 · 2026-11-16

范围：整个 VitePress 文档站的共享导航、指南、组件目录与详情、组合组件、AI、DND、Motion、Icons、路线图及质量矩阵。组件库 packages 源码、导出和 API 不修改；原工作区未提交内容保持原状。

## 设计顺序

1. Taste：沿用真实品牌蓝与本地字体，建立阅读优先的统一文档体系。共享侧栏、正文和页内目录；目录按使用场景组织。
2. Impeccable：统一明暗色 token、阅读宽度、表格、代码、提示块、示例容器与窄屏布局。目录和专区支持搜索、结果数量、无结果提示及清除。启用并本地化全站搜索。
3. Emil Kowalski：保留短暂的颜色反馈，焦点即时显示；取消目录滚动入场和侧栏高度动画。指针 hover 独立处理，尊重 reduced-motion。保留真实组件示例交互。
4. Hallmark：去掉重复眉题、装饰编号及重复卡片层级，用行式目录表达真实名称、状态、用途和目的链接。独立复查发现表格多余空白边框，已修复并重拍确认。

## 验证与边界

- 文档生产构建通过；现有大 chunk 提示仍存在。
- 12 类页面在 1440px / 390px 的浏览器检查：每页一个 H1，无横向溢出，无 pageerror。
- 明暗模式抽查指南、组件目录、Button、AI、Icons。指南和目录页面无 axe serious/critical；Button 示例仍有原库语义色按钮的对比度问题，按范围不改库样式。
- Hallmark 对共享样式和两个目录模板的渲染扫描：0 FAIL、0 REFLEX、0 WARN。
- Impeccable 源文件扫描无报告项；该扫描采用 regex，不能替代浏览器可访问性检查。
- Taste 的上一轮独立 gate 未通过，原因与结果保留于首页记录；不将这次重构描述为四套工具全部自动通过。
