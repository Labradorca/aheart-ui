## 按指定顺序执行

1. Taste：软件产品页面，面向 Vue 开发者，主动作是阅读安装指南。以真实组件取代静态工作台装饰。保留已有品牌蓝；使用 Familjen Grotesk 拉丁字体及系统中文字体，字体本地托管并附 OFL。
2. Impeccable：统一层级、移动布局、控制尺寸和焦点；修复暗色标签与代码对比度、320px 按钮换行。检测器在未修改的其他文档样式发现两处既有侧边强调边框，未扩大修改范围。
3. Emil Kowalski：一次首屏进入；指针 hover 与按压反馈；不增加循环或滚动追赶动画。
4. Hallmark：移除装饰性眉题、伪状态、假窗口和重复卡片。真实组件体验区清楚注明不保存数据。独立新上下文审查最终桌面/手机截图，结论 ship。

| Before | After | Why |
| --- | --- | --- |
| 静态 Agent 面板的伪运行状态 | AInput / ASwitch / AButton / AConfigProvider 真实交互 | 让组件本身说明产品 |
| 泛化 hover 与装饰 | 160ms 按压反馈、180ms 链接反馈，明确 transform 属性 | 保持即时、可中断 |
| 键盘与指针共享过渡 | focus-visible 时即时反馈，减少动态效果时关闭位移动画 | 键盘速度与可访问性 |
