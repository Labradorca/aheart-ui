## 负责人本轮决定（按原指令整理）

1. 预算分两类：
   - 叶子组件入口（基础包中只渲染自身的组件）：沿用 M1 数值，组件 CSS ≤ full 25%，theme ≤ 5%，theme + 组件 ≤ 30%。
   - 复合入口（AIForm、Workbench 等，按设计依赖多个基础组件族）：CSS 闭包必须等于“自身样式 + 其声明依赖入口样式”的并集，不得包含声明依赖之外的任何选择器；不适用 25% 比例线。闭包大小、各依赖占比要记录，并作为后续版本不得回升的基线。
   - JS 预算两类都不变：gzip 小于 full Plugin，相对 root named 增量 ≤ max(512 B, 1%)。
2. AIForm 必须修模块图：字段渲染改为精确公开子入口导入，不再经过根 barrel；验收时模块图只允许 13 个字段控件族及其声明的传递依赖，106 个越界模块必须清零。
3. 保持不变：13 类字段、对象身份、props/events/expose、两个试点的业务源码。
4. peer 版本：精确子入口要到 1.4 才存在。AI 包对 aheart-ui 的 peer 下限如需提到 ^1.4.0，先给负责人看影响说明再改，不直接改。
5. 先在设计文档列出哪些入口属于复合入口，交负责人确认后再恢复 V1 实现。其他叶子组件若有任何一个超出 25%，照旧停下来报告。

**本决定不包含开 PR、改版本或发布的授权。** 既有 V1 合并、Pages、npm、tag 的独立授权边界继续保留。
