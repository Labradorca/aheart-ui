# AI peer 下限：精确导入后的影响与待决定项

状态：**已到负责人要求的peer停止点；未修改peer、包版本或锁文件。** 这不是开PR、合并、部署、npm或tag授权请求。

## 现在为什么需要决定

AIForm的已实现运行时导入现在使用13个公开基础家族；V0/1.3 API中只有Button和Select已有精确路径。新增11个路径为：checkbox、date-picker、form、input、input-number、radio、switch、textarea、time-picker、tree-select、upload。对照数据见 [原影响清单](../classification/peer-impact.json)。类型路径Tree也属于这次公开入口扩展，不能把类型消费遗漏在迁移验证之外。

当前AI源码peer是`workspace:^1.1.0`，真实pack转为`^1.1.0`；它仍允许安装缺少这些路径的公开基础包1.1–1.3组合，因此已不准确描述新AIForm的最低能力。推荐未来下限为**源码`workspace:^1.4.0`，出包`^1.4.0`**。

| 方面 | 具体影响 |
| --- | --- |
| 原有用户 | 升级含本改动的AI包时，基础包也须升级到提供新子入口的1.4.x或后续兼容1.x；锁在1.1–1.3的组合不再属于支持范围 |
| 两个试点 | 业务源码保持冻结；依赖包组合及锁文件升级需如实记录。未用改业务源码规避兼容问题 |
| 当前本地候选 | 基础包版本仍1.3.0，只因本地未发布产物已增加exports才通过本次探针；这证明精确导入实现，不证明公开1.3可用，也不证明^1.4安装组合已经通过 |
| 单独修改peer后 | 当前1.3.0候选不满足^1.4.0。仍需等基础包版本的**单独授权**后，才能完成正常满足新peer的版本组合验收；不能自动升级版本，也不以force/legacy-peer-deps制造通过 |
| 后续落盘范围 | 获准后修改AI的peer及相关release-contract断言/必要锁文件记录；AI、基础、DND的version字段仍不改。具体安装工具行为以当时实际命令记录为准 |
| 发布顺序 | 先有提供新路径的基础包版本，再发布依赖它的AI包；每次改版本、开PR、合并/Pages、npm、tag仍分别授权 |
| 回退 | AI、基础包及消费锁文件退回配套旧组合；新AI不得声称仍支持旧基础包 |

Vue peer、DND依赖、13类字段、对象身份、props/events/expose均不随本peer建议改变。AIForm的106项越界已在本地tarball图清零，JS预算通过；完整V1验收仍未完成。

**需要负责人单独决定：是否授权把AI对基础包的peer下限改为^1.4.0（源码保留workspace协议），并同步相关契约/必要锁记录。该授权不包含任何包版本修改或发布。** 在收到答复前，本轮不继续其余V1实现。
